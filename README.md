# แมวทาโรต์ 🐱🔮

เว็บไซต์ส่วนตัวสำหรับเรียนไพ่ทาโรต์ ใช้ภาพประกอบเป็นแมว 78 ใบ พร้อมระบบทำนายด้วย AI (Google Gemini)

## โครงสร้างไฟล์

```
site/
  index.html          หน้าคลังไพ่ — ดูไพ่ทั้ง 78 ใบ พร้อมความหมาย 4 ด้าน
  reading.html         หน้าทำนาย — เลือกไพ่ 3 ใบ + พิมพ์คำถาม แล้วให้ AI ทำนาย
  css/style.css        สไตล์ทั้งเว็บ
  js/learn.js           โค้ดหน้าคลังไพ่
  js/reading.js         โค้ดหน้าทำนาย + การเชื่อม Gemini API
  data/cards.json       ข้อมูลไพ่ทั้ง 78 ใบ (ความหมาย 4 ด้าน + ที่อยู่ไฟล์ภาพ)
  assets/cards/         ภาพไพ่ทั้งหมด (major/ 22 ใบ, minor/ 56 ใบ)
```

## ใช้ AI ทำนายยังไง

หน้า "ทำนาย" ต้องใส่ Gemini API key ของตัวเอง (กดปุ่ม "ตั้งค่า" มุมขวาบนของแถบสถานะ) —
คีย์นี้ถูกเก็บไว้ใน **localStorage ของเบราว์เซอร์คุณเท่านั้น** ไม่ถูกเขียนอยู่ในไฟล์โค้ดเลย
ปลอดภัยแม้ repo บน GitHub จะเป็น public

ขอ API key ฟรีได้ที่ https://aistudio.google.com/apikey

> ถ้า Google เปลี่ยนชื่อโมเดลในอนาคต (ปัจจุบันใช้ `gemini-3.6-flash`) แก้ได้ที่ช่อง "โมเดล" ในหน้าตั้งค่าเลย ไม่ต้องแก้โค้ด

## รันดูในเครื่องตัวเอง

เปิดไฟล์ `index.html` ตรงๆ ก็ดูได้ระดับหนึ่ง แต่การโหลดข้อมูลไพ่ (`data/cards.json`) ผ่าน `fetch`
บางเบราว์เซอร์จะบล็อกถ้าเปิดจากไฟล์ตรงๆ (`file://`) — ถ้าอยากรันเต็มรูปแบบในเครื่อง ให้เปิดผ่าน local server สั้นๆ เช่น

```
cd site
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000
